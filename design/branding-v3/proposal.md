# 第三版：命名、Logo 与界面设计提案

本轮按“先给设计图和名字”交付设计预览，未修改应用功能、名称、图标或安装包。设计延续冰川银、浅蓝与深蓝文字，品牌图形重新设计。

## 软件命名

| 方案 | 名称 | 含义 | 图形方向 |
| --- | --- | --- | --- |
| A，推荐 | 途映 | 旅途与影像，强调保留路上的画面，适合不同品牌车型 | 用一条道路与播放符号的负形组成简洁标记；钴蓝底、白色主体 |
| B | 行迹 | 行程留下的记录，偏工具与可靠感 | 路线与记录点组成连贯图形；深蓝底、冰蓝点缀 |
| C | 驭光 | 驾驶与光影，偏科技和速度感 | 抽象向前的光束或翼形；冰银底、蓝色主体 |

这是创意命名提案，尚未检索商标、应用市场或域名可用性。品牌板用于挑选方向；定稿后的正式图标应制作可编辑矢量和各平台尺寸。

## 设备页

- 左上角品牌使用新名称与新 Logo；现有自定义软件显示名称能力保留。
- “我的记录仪”旁显示小铅笔，点击直接修改设备页标题，默认值仍为“我的记录仪”。
- 已识别车型旁也显示小铅笔，可以把“星越L2026款”改成自定义名称，例如“小雷的座驾”。显示别名与自动识别的车型资料分开保存，重新连接不覆盖用户别名；提供恢复识别名称。
- 点击记录仪图片打开图片操作抽屉：选择透明 PNG / WebP、恢复默认图片、取消。图片保持透明通道与原始比例，居中适配。
- 选定图片复制并保存到应用本机资料中，重启与覆盖升级后仍生效。恢复默认只恢复设备展示图，不修改车辆资料或录像。
- 统一提供“外观自定义”恢复入口，区分恢复页面标题、恢复车型显示名、恢复设备图片。
- 移除演示入口、演示标签及示例设备，首页只显示真实设备与本机保存资料。

## 连接方案选择

采用可滚动的圆角底部抽屉，固定标题和确认按钮。放弃系统原生长下拉框和整段大文字按钮，使用单选卡片、车型标签和选中描边。

1. 第一张为“自动连接”，标记推荐。
2. 三个车型卡片完整显示对应车型，不用“等”省略；车型标签自然换行。
3. 通用一、二、三放在“未列出的车型可尝试”下，使用三个较小的单选项，与自动及具体方案保持同一单选关系。
4. 底部显示“下次自动使用已选方案”，确认按钮为“使用此方案”。

| 方案 | 完整车型文字 |
| --- | --- |
| A7 | 银河A7、星耀7、M7、TT、2026款星舰7、2026款星瑞、2026款博越、2026款星越L、星愿 |
| E5 | 银河E5、星耀8、2025款星舰7、2025款星瑞 |
| L6 / L7 | 银河L6、银河L7、2023/2024款领克07、2023/2024款领克08；另列原 APP 提示“可使用吉行小助手的车型” |
| 通用一 / 二 / 三 | 分别使用现有 E5 / A7 / L6 兼容协议 |

车型分组依据用户提供的原 APP 截图和既有 APK 分析，表示方案选择范围，不增加未经实测的兼容保证。

## 播放器

- 普通与全屏播放器都移除停止按钮，保留播放、暂停、前后跳转、进度条和全屏切换。
- 播放/暂停保持正中；左侧为音量与倍速，右侧为全屏。
- 倍速最高改成 4×，保留已有低倍速与 1.25×，增加 3×、4×；倍速用小面板选择，当前速度清楚标记。
- 点击录像先普通播放；全屏手势、缩放与拖动沿用现有方案。
- 分享、截取与打码仍在文件操作抽屉，不重新堆到播放按钮区域。

## 传输页

- 移除右上角 Wi-Fi 连接按钮。
- 保留任务暂停/继续、删除、清理记录及已有批量任务操作。
- 不增加演示任务；连接管理统一从设备页进入。
