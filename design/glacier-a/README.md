## 落地

- 浅色雪山与湖面背景，首页不再使用大块外框卡片。
- 居中的设备展示、双层冰蓝环线、车型、连接状态与主要操作。
- 三个快捷入口和统一底部导航。
- 录像页使用紧凑的双列缩略图、时间、分类、保存与详情操作。
- 搜索/日期筛选通过顶部按钮展开，批量选择保留为直接可用的操作。
- 未连接、连接中、已连接、演示、下载进度和错误反馈均由真实应用状态控制。

独立素材已保存在 `public/images/glacier-background.png` 和 `public/images/glacier-device.png`。设备图是概念视觉，不表示车辆内置记录仪的真实硬件外观。界面与素材使用 React/CSS/本地图片实现，没有把整张设计图当作界面铺上去。
