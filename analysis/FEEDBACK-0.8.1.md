# 吉行影记 0.8.1：实机反馈修正

本次根据 2026-10-28 的设备截图及用户反馈修复。技术栈保持原样，产品界面不再显示技术栈名称。

## 状态字段

- 解析完整层级键名 `Camera.Menu.CardInfo.LifeTimeTotal=58.1G`、`RemainLifeTime=19.4G`，兼容无 B 后缀的 K/M/G/T 单位。
- 总容量、可用空间不再依赖分类计数是否齐全；缺少分类占用字段时不编造占用图。
- `Camera.Menu.SD0=READY` 显示“正常”；保留原 `Sd=0` 协议支持。
- 控制器版本兼容 `MCUVer`、`MCUversion` 等名称。补充只读 DVR、MCUversion 和 Camera.Menu.MCUversion 查询，额外查询限制超时。版本值与固件版本分别展示，不用截图里的固件 0001 冒充控制器版本。
- 容量和状态映射根据截图复现；控制器响应使用原 APK 字段与模拟返回验证，尚未再次连接用户车辆确认实际返回值。

## 页面和播放器

- 首页默认标题合并为“星越L · 吉行影记”。原车型、年款、配置作为标题下方可点击标签，移除下方重复的大车型标题，保留自定义标题、别名和图片。
- Android 原生全屏控制栏采用绘制图标，播放/暂停为同一按钮，进度、时间、更多和退出图标位于同一行。浏览器播放器同步修改。
- 修复触摸结束时无条件重新显示控制栏以及暂停轮询强制显示的问题；点画面依次显示、隐藏，拖动操作后显示，播放时可定时隐藏。
- 下载固定保存到系统相册，移除下载目录选择和下方说明；旧下载目录设置自动归一到相册。已有文件索引及手动文件另存授权保留。
- 播放器默认常亮，旧设置即使为 false 也不再关闭常亮，设置页移除该开关。
- 前端阻止 contextmenu 和拖拽菜单，关闭图片长按 callout 与非输入区域选中；Android WebView 消费长按事件。技术栈字样从界面移除。

## 遮挡车架号

旧默认遮挡区为 x=0.73、width=0.21，只到画面 94%，右边仍留 6%。默认区改为 x=0.62、y=0、width=0.38、height=0.09，覆盖右上角直到边缘。

- 预览改为完全不透明黑块。
- Android 使用 alpha=255、SRC 绘制模式及向外取整的像素边界；桌面 FFmpeg 同步使用不透明填充和向外取整，避免画面边缘剩余列。
- Android 编码完成后解码开头、中间和结尾画面，检查遮挡区内部所有像素。发现明显亮色、解码失败或校验失败时不发布文件到相册，并删除该临时成品，提示失败。
- 原文件保留。以前保存的遮挡不完整视频需从文件菜单重新进入“截取与打码”导出；升级不会自动重写用户的旧文件。
- `tools/check_mask_export.py` 实际生成并解码 H.264 文件：三个时间点的遮挡区最高 RGB 均为 1（近黑），包含最右侧列；其他区域仍为白色测试源。该验证针对本机 FFmpeg 编码输出，不代表手机 Media3 GPU 已完成实测。
