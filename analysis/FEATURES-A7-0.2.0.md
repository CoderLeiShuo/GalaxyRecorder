# 0.2.0 星越 L 功能与验证记录

日期：2026-10-28。适配目标：2026 款星越 L，原 APK 中的 A7 协议方案。

技术栈保持 **Tauri 2 + React + TypeScript + Rust**。Android 的解码、编辑、扫码、系统目录和相册由 Tauri 的 Kotlin 插件提供；页面和播放器控件仍由 React 绘制。

## 这次三个问题的处理

1. **时长与封面**：之前列表只包含文件信息，未接入媒体元数据读取。现在按需请求 `/thumb/mnt/mmc/Normal/…` 或 `/thumb/mnt/mmc/Event/…`，并通过 HTTP Range 寻找 MP4 `moov/mvhd` 时长索引。设备不提供缩略图或索引时，尝试系统媒体解码抽帧。列表仅为临近可见区域的卡片读取元数据，同时最多两段，并缓存成功结果；失败显示真实的读取状态，不编造时长。
2. **播放**：Android 使用 Media3 ExoPlayer 解码在线 HTTP MP4、本地文件和 RTSP，避开 WebView 对记录仪片源的限制。React 自绘播放、暂停、拖动、前后跳转、倍速、音量、缩放和全屏按钮；Android 全屏切换横屏，支持双指缩放。桌面 MP4 使用隐藏原生控制栏的视频元素，加相同的 React 控件；本地流代理支持 Range 和 HEAD。
3. **保存位置**：设置可选应用媒体库、系统相册或指定目录。Android 使用系统目录授权并持久保存权限，桌面使用系统文件夹选择器。导出失败时保留应用内下载副本并提示。选择外部目录或相册会产生额外副本；改变设置不搬迁历史文件。

## 验证结果与使用边界

- Rust 31 项测试通过，其中媒体测试使用本机 HTTP 服务验证真实 Range 请求、尾部 MP4 索引读取与本地视频响应。
- 前端 9 项测试通过，生产构建通过。
- 浏览器界面 12 项检查通过：封面与时长、隐藏浏览器控制栏、倍速、静音、跳转、全屏、移动布局、剪辑打码参数、目录选择、保存设置、状态显示、格式化确认。设备调用使用模拟桥接，视频元素实际解码演示 MP4。
- Android ARM64 Release APK 构建与签名校验通过；产物信息以 `output/build-info.json` 为准。
- 本环境没有已连接手机、可用模拟器或可达的实车记录仪。Android 原生播放、目录授权、相册写入、后台传输、硬件导出及设备控制仍需要手机/实车验收，不能把编译和模拟测试等同于已实测可用。

电脑实时预览、抽帧回退和剪辑打码使用系统可执行的 FFmpeg/FFprobe；Android 使用 Media3 与系统媒体 API，无需另装 FFmpeg。电脑实时画面当前为 MJPEG 预览，不带声音。

本轮按用户确认先补齐星越 L 本地功能。其他车型的 E5/L6 协议、iOS、原作者服务器上的更新、公告、统计及远程车型配置不包含在本版中。后续自有更新服务需独立实现，不能把原作者服务器当作本项目后端。

## 建议实车验收顺序

1. 覆盖安装 0.1.3，连接热点，核对普通/紧急列表、时长和封面。
2. 播放一段原片，拖动进度、暂停、倍速与全屏；下载后断开热点，再离线回看。
3. 在设置中选一个系统文件夹，下载一段，核对目录中的 MP4；再验证保存到相册与分享。
4. 导出短片及打码片，检查起止时间与遮挡画面；检查生成的封面也已打码。
5. 验证实时画面、后台下载、取消和重试，最后逐项测试设备控制。格式化只在确实要清卡且已完成备份时执行。
