# 0.8.5：01 原版基准 Logo 与传输按钮布局

## 改动

- 采用最新细化图左上角的 01「原版基准」：蓝色渐变底、带肩线白色相机框、微光蓝色镜头、右上红色录制点及右下道路标记。正式母版通过内置 image_gen 提取，见 [设计源文件与提示词](../design/app-icon-v4/README.md)。统一 Android 常规/圆形/自适应图标、桌面图标和网页图标。
- 移除设备页右上角加号连接按钮，保留设备页“连接记录仪”、下拉重连、“管理连接”及设置内的连接入口。
- 每个传输任务底部单独一行放置两个等宽按钮：左侧为暂停、继续下载或查看录像，右侧为删除任务。增加图标、区分操作颜色并扩大点击区域；进度及错误提示单独占据上方，长提示不再挤压按钮。
- 暂停、断点续传、删除任务的原有调用及已保存文件保留行为不变。设备页标题、车型及记录仪图片编辑保留，顶部 Logo 继续不显示。
