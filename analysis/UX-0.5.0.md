## 相册文件与兼容

- Android 保存后记录实际 MediaStore URI；旧 Android 使用公共视频目录，文件夹模式使用已授权文档 URI。播放、读取元数据、分享、重命名与删除使用实际文件。
- 原生端只接受由本应用登记的外部录像，以及已允许的旧版媒体目录文件。不会因为新增 URI 支持而放开任意文件访问。
- 旧版本应用内录像继续读取，不在升级时批量移动或删除。对旧文件选择“保存到相册”会发布到相册并清理对应本地源文件。
- 相册保存完成但应用尚未提交索引时发生进程中断，原生端持久化的发布记录会避免重试重复创建同一相册文件。
- 先保存文件索引，再清理内部临时源文件；索引写入失败时保留可恢复的源文件。临时清理失败会报告警告，避免通过重试重复创建相册文件。
- 在系统相册中删除文件后，回到应用会刷新“已保存”列表。文件菜单中的删除明确提示会删除相册或文件夹中的文件，记录仪原片保留。
- 指定一次“另存到文件夹”不会暗中改变后续下载的默认位置；全局位置仍可在设置中调整。

## 安装后验收

1. 覆盖安装后查看新图标，点击软件左上角名称修改，退出重开确认保留。
2. 点击一段录像，应直接全屏。双指放大，单指拖动，双击复位；退出全屏后应看不到放大按钮。
3. 在录像卡片点击更多按钮，仅出现文件菜单；全屏中的“更多”同样打开菜单。
4. 在默认相册设置下保存一段录像，确认系统相册中存在文件，应用中可离线回看、分享和重命名。
5. 在菜单选择删除，确认后相册文件也被删除；车机原片保留。另检查旧版本保存录像仍能读取。

安装包与构建记录位于 output/galaxy-recorder-0.5.0-gallery-gestures-arm64-test.apk 和 output/build-info-0.5.0.json。
