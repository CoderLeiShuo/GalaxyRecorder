# 设备、连接方案与播放器界面调整（仅源码）

后续状态：用户已授权打包并选定名称“吉行影记”，界面改动现已纳入 0.8.0。下面保留原先仅修改源码阶段的记录；最新状态见 [0.8.0 发布说明](RELEASE-0.8.0.md)。

日期：2026-10-28。按用户确认的 `design/branding-v3/interface-concept.png` 落地，保留原有设备图、应用名称与 Logo。技术栈维持 Tauri 2、React、TypeScript、Rust 与 Android Kotlin 媒体插件。

## 已完成

- 设备页保留 `public/images/glacier-device.png`，车辆名称、配置、年款及连接状态集中展示在醒目的卡片里。快捷功能改为两列卡片。
- 点击标题可改名；点击车辆名称可编辑显示名称，另设车型与配置信息入口。显示名称按设备标识单独保存，重新识别车型不会覆盖它，支持恢复原车型名称。
- 点击设备图片可选择 PNG/WebP；保留透明像素和比例，长边最多 1200 像素，规范化为 PNG 并保存到应用设置文件，不依赖相册原文件或临时授权。支持恢复原图。取消选择、无效图片和保存失败均保留原设置。
- 标题、图片、车辆名称分别恢复默认，互不影响。写入设置仍使用串行锁和临时文件原子替换；普通设置保存不会覆盖这些外观设置。
- 连接方案改为卡片选择抽屉，完整列出 A7、E5、L6/L7 适用车型和三个通用模式，自动连接保留为推荐项。确认后才写入已选方案，关闭或取消不改变选择。
- 移除产品中的演示入口、虚拟录像、模拟下载和演示分支。播放测试 MP4 移入 `tools/fixtures/drive.mp4`，不随前端产品发布。
- 播放器普通界面与 Android/浏览器全屏界面均移除停止按钮；倍速支持 0.5、1、1.25、1.5、2、3、4。Android Media3 实际速度上限同步提高至 4。
- 保留中间播放/暂停、左侧音量/倍速、全屏进度/亮度/音量手势、双指缩放拖动、文件操作抽屉、保存到相册与下载提示。
- 移除传输页右上角 Wi-Fi 按钮；自动连接、断网状态更新、下拉刷新、续传和删除任务保留。
