# 0.6.0：播放器控制与设备页效果图

技术栈保持 Tauri 2 + React + TypeScript + Rust，Android 原生解码和系统窗口操作使用 Kotlin 插件。

## 播放器

- 点击录像先打开普通播放器。全屏仅通过按钮进入；Android 横屏、隐藏系统栏，返回键或“退出全屏”按钮恢复普通播放器。
- 普通播放器采用三列布局：左侧音量和倍速，中间前后跳转及居中的播放/暂停，右侧停止和全屏。
- 全屏控制栏提供独立的播放、暂停、停止、更多及退出全屏按钮，并显示当前时间、总时间和可拖动进度条。播放时三秒自动隐藏，暂停时保留。
- 停止暂停播放并回到录像开头，不删除文件。实时流没有录像进度可供归零。
- 全屏原始比例下，水平滑动相对手势开始位置调整进度，松手后提交一次跳转；一次全宽滑动最多跨越两分钟，短片按总时长计算，防止跳出录像范围。
- 左半区竖直滑动调整亮度（最低 5%），右半区竖直滑动调整播放音量（0–100%）。按触摸起点锁定调节类型，过滤轻微抖动，显示调节提示。
- 双指缩放优先，放大后单指拖动画面；双击复位。多指操作不会触发一次进度跳转。
- Android 亮度调整只作用于当前应用窗口，退出全屏或关闭播放器时恢复原值；不写系统亮度设置。浏览器预览使用视频亮度滤镜，退出时恢复。
- Android 原生音量状态同步回 React。全屏坐标不覆盖普通窗口的保存坐标。
- 截取与打码入口移到文件抽屉。选择该项在普通视图显示原有编辑器，保留剪辑范围与遮挡区域导出能力。
