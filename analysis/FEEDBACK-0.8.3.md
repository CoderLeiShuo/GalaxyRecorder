# 0.8.3：下拉重连与录像日期分组

## 设备页

- 未连接时，在设备页顶部向下拖动并松开，可直接重连。优先探测记住的记录仪，再回退到自动搜索。
- 已连接、正在连接或正在下载时，不通过下拉发起另一轮连接；正常会话保持不变。
- 下拉可从标题、配置、记录仪图片等区域开始。短距离拖动、横向手势和取消触摸不发起重连。成功下拉后的兼容点击会被消费，避免误打开图片编辑器；后续正常点击仍可用。
- 移除旧的“下拉刷新，重新连接记录仪”按钮、文案、回调名称与对应样式。拖动过程中只显示临时连接指示。
- 增加设备页顶部留白：手机页头含安全区时至少 64px，标题顶部另留 16px。移除界面左上角的软件 Logo，保留标题、车辆配置和记录仪图片的直接编辑功能。

## 录像与设置

- 全部、普通、紧急及已保存录像都按录像日期分组，日期和组内时间从新到旧显示。没有日期的录像单独放在“日期未知”组。
- 日期标题显示当前筛选条件下该日期的完整数量；仍每次显示 60 段，加载更多可以延续同一天并展示后续日期，不重复或遗漏录像。
- 保留网格/列表切换、搜索、日期筛选及跨日期批量选择。
- 移除设置页右上角的 Wi-Fi 按钮，设置中的“管理连接”入口继续可用。

## 本轮验证

- 前端 36 项通过，TypeScript/Vite 生产构建通过。
- Chrome：媒体界面 37、连接状态 13、车辆与方案 20、日期分组及布局 16 项通过，共 122 项单元与界面检查。
- 日期分组检查使用 71 段跨日期录像，覆盖 60 段分页边界、紧急/已保存分类、日期与搜索组合、无日期分组及跨日期选择。
- 下拉检查覆盖断网后重连、图片区域拖动不触发换图、健康连接不重新探测、短/横向/取消拖动不重连。
- UI 中记录仪和系统调用为模拟桥接，未操作或安装用户手机。Android 原生功能沿用 0.8.2。
