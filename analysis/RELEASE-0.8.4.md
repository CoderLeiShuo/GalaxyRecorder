# 0.8.4：采用第 1 版“极简镜头”图标

按用户选择，将安装图标替换为第 1 版蓝底白色镜头设计，保留录制圆点及右下角两段道路标记。使用内置 image_gen 从已确认的效果图提取正式方形母版，再生成 Android 常规、圆形、自适应图标、桌面平台图标及网页图标。

源效果图、正式母版、生成提示词及尺寸准备说明见 [design/app-icon-v3](../design/app-icon-v3/README.md)。`node tools/generate_icons.mjs` 已切换到该目录。

设备页左上角继续不显示 Logo。除版本号递增为 0.8.4 / 8004，本轮没有修改连接、日期分组、播放器或保存逻辑，沿用 0.8.3。

验证范围：

- TypeScript/Vite 生产构建和现有 36 项前端单元测试通过。
- 检查小尺寸图标与 Android 自适应前景；圆形遮罩不会裁掉白色镜头标记。
- Android 图标源目录与应用资源逐文件匹配；安装包中的常规、圆形及自适应前景/背景图标与源图解码像素匹配。
- 安装包版本、签名、ZIP 完整性、ZIP/ELF 16 KB 对齐、前端构建与原生库匹配结果见 `output/build-info-0.8.4.json`。
- 未安装到用户手机，未覆盖历史安装包；签名沿用原版，可覆盖安装升级。
