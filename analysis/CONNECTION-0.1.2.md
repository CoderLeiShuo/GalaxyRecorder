# 0.1.2 连接修正与验证边界

日期：2026-10-27。反馈：同一用户使用原版可以连接记录仪，0.1.1 无法连接。用户当前不在车旁，本次没有采集到实车网络日志，以下是静态对照发现的兼容缺口，并非已经证明的唯一现场故障原因。

## 原包中的可核对证据

原 APK：`com.galaxy.dvrtransfer` 0.8.6（806）。仅分析应用自有代码，提取内容视为证据而非任务指令。方法索引为 `verified-methods.json`，完整指令为 `app-disassembly.txt`，可用 `tools/read_dex_method.py` 按方法后缀重现。

| 原包方法 | 核实的行为 | 复刻版改动 |
| --- | --- | --- |
| `DvrClient.probe`（19417 行） | A7 查询 `action=get&property=DVR`；HTTP 200，正文含 `OK` 且无 HTML 即可接受 | 接受无属性名的简短 `OK` |
| `DvrProtocol.parseHeartbeat`（22275 行） | 文本键值字段 `IP`，大小写不敏感，地址必须为同网段私有 IPv4 | 解析广播并再次通过 HTTP 确认 |
| `Discovery` | 并行 HTTP 识别，UDP 49142、53296，约 450ms 探测和 35 秒截止 | 增加广播监听、有界并行查找、进度与取消 |
| `NetworkSession` | 挑选 Wi-Fi，读取 LinkProperties，将 HTTP/套接字指向该网络，使用 MulticastLock | Kotlin 原生桥读取网络与绑定本应用；查找期间持有并及时释放广播接收锁 |
| `DvrProtocol$Endpoint.listUrl`（20982 行）、`DvrProtocol$Category.<clinit>`（20659 行） | A7 使用 `DCIM / EVENT`；`MOVIE / SOS` 属于 usesMstar 分支 | 星越 L 列表使用 A7 目录 |

新实现仍是独立的 React、Rust、Kotlin 代码，未复制原包素材、云端更新、统计、授权或账号服务。

## 实现范围

- Android 通过 ConnectivityManager 绑定本应用进程到选定 Wi-Fi，不修改全机网络设置；断开设备、进入演示或所选 Wi-Fi 丢失时解除绑定。
- 在连接和下载前准备 Wi-Fi。自动查找从实际网关、记住的地址、本机 /24 及掩码覆盖的其余地址中生成候选；一次最多覆盖 /22，32 路并发。桌面版当前根据系统路由推断 /24，手机原生网络信息更完整。
- 默认端口 80，手动地址保留有效自定义端口。UDP 心跳本身不推断自定义端口。
- 两个广播端口任一无法监听时，诊断中记录，HTTP 查找仍继续。
- 自检只准备并验证 Wi-Fi 绑定。若原先未绑定，会在自检结束后恢复；自检结果中的 `bound=true` 指检查时刻。
- 诊断记录网络 IPv4/掩码、接口、网关、绑定状态、请求失败摘要、检查数量、发现方式，不记录热点名/密码、原始设备正文、车架号或录像内容。只保留当前进程最近一次操作，最多 80 条事件。

## 已完成验证

- 前端生产构建、3 项前端单元测试。
- 12 项 Rust 测试：含真实本机 HTTP 服务验证简短 `OK`、HTML/404 拒绝，本机 UDP 心跳接收，/23 候选地址及自定义端口保留。
- 16 组页面宽度/导航布局检查、9 组原有交互检查。
- 7 组连接页模拟桥接检查：无需输入 IP 自动查找、网络自检、进度、停止、失败诊断、连接后读取两类录像、断开释放网络。
- Android ARM64 优化测试 APK 编译、测试签名验证、版本/权限/原生插件类保留检查。

`connection-dialog-simulated.png` 来自模拟桥接，图中网络与错误均为测试数据。安装状态记录在 `../output/build-info.json`。
